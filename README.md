# ZippoWorkz Website

Status: PUBLIC WEBSITE / GITHUB PAGES READY

## Zweck
- Eigene, professionelle Webpräsenz für ZippoWorkz vorbereiten.
- Später als Firmen-/Projektwebsite für TikTok Developer Profile und weitere Plattformprüfungen nutzen.
- Kostenlose GitHub-Pages-Adresse vorgesehen; keine Domain gekauft und keine Firewall-/Cloudflare-/DNS-Änderung erforderlich.

## Lokale Vorschau
`python -m http.server 8771 --bind 127.0.0.1 --directory C:\Zippoworkz\Web\Zippoworkz`

Dann lokal auf dem VPS:
`http://127.0.0.1:8771/`

## Vor öffentlichem Launch zwingend
1. Eigene Domain auswählen und Owner-Kostenfreigabe einholen.
2. Domain registrieren und DNS auf den vorgesehenen Webserver zeigen.
3. HTTPS aktivieren.
4. Impressum mit echten, erforderlichen Anbieterangaben vervollständigen.
5. Datenschutz an finalen Hoster / Dienste anpassen.
6. Funktionierende Kontaktadresse auf eigener Domain ergänzen.
7. Öffentlichen Readback auf Desktop + Mobile prüfen.
8. Erst danach Domain im TikTok Developer Profile eintragen und erneut einreichen.
